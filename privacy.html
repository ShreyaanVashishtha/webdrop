Zero-Knowledge Architecture

Privacy Policy

Last updated: October 2026

1. Core Commitment: Zero Server Storage

WebDrop is engineered from the ground up as a direct peer-to-peer (P2P) file transfer system. We believe your personal files, photos, videos, and text snippets should never pass through or be retained on any central intermediary storage server.

Summary: Your files travel directly from device to device over encrypted WebRTC channels. WebDrop servers do not store, copy, analyze, or hold your files.

2. End-to-End Encryption (E2EE)

All WebRTC data connections employ industry-standard DTLS/SCTP wire encryption. Furthermore, WebDrop implements application-layer Zero-Knowledge AES-256-GCM encryption powered by ephemeral ECDH (P-256) key exchange negotiated via the native Web Crypto API (crypto.subtle).

Cryptographic keys are created locally in your browser memory and discarded immediately upon disconnection. Intermediaries, network operators, or STUN signaling nodes cannot decrypt your file payload.

3. Ephemeral Signaling & Local Radar

To help devices discover each other without user accounts:

  • Presence Records: When radar mode is active, an ephemeral record containing your 5-digit PIN, public IP hash, and chosen device nickname is recorded in a Google Firebase Firestore database.
  • Automatic Expiration: Presence records automatically expire and self-delete after 6 seconds of inactivity and are explicitly removed when closing or reloading the browser tab.
  • No Identity Tracking: We do not log IP addresses, create user profiles, or link sessions to individuals.

4. Local Storage & Client-Side Data

WebDrop utilizes client-side storage technologies strictly for local utility functions:

  • localStorage: Remembers your custom device name (webdrop_device_name) and random ephemeral device ID.
  • IndexedDB: Temporarily caches files shared via the native PWA Web Share Target sheet until they are queued to a connected device.
  • OPFS (Origin Private File System): Streams large incoming file chunks directly to local browser sandboxed storage to avoid memory exhaustion, automatically cleared upon download assembly or cancellation.

5. Tracking, Cookies & Analytics

WebDrop does not use advertising cookies, third-party tracking pixels, invasive fingerprinting scripts, or cross-site behavioral telemetry.

6. Third-Party CDNs & Services

Static libraries (Tailwind CSS, PeerJS, Phosphor Icons, QRCode.js) and STUN servers are delivered via reputable global CDNs and Google STUN (stun.l.google.com:19302). These services only receive standard HTTP headers required to serve the script assets and establish NAT traversal.

7. Open Source & Transparency

WebDrop is transparent and open source. You can inspect the complete source code, verify all cryptographic operations, or host your own instance by visiting our GitHub repository .
